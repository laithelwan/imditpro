# تطبيق ويب لتعديل الصور ووصف الصورة بالذكاء الصناعي 

## 📌 وصف المشروع
هذا المشروع عبارة عن تطبيق ويب لتعديل الصور يتيح للمستخدم:
- رفع الصور من الجهاز
- تطبيق فلاتر لونية مختلفة
- قص الصور (Crop)
- تعديل الاضاءة والتشبع وما شابه
- معاينة التعديلات بشكل مباشر
- تحميل الصورة بعد التعديل أو مشاركتها

يهدف المشروع إلى تطبيق مفاهيم الوسائط المتعددة مثل معالجة الصور، التعامل مع Canvas، والتأثيرات البصرية باستخدام تقنيات الويب.

---

## 🛠️ التقنيات المستخدمة
- HTML5
- CSS3
- JavaScript
- Canvas API
- Django (Back End)
- GitHub (إدارة الإصدارات)
- Render (استضافة المشروع)

---
