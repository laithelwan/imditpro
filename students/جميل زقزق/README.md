الاسم : جميل صالح زقزق 
الرقم الجامعي : 20040102



تهدف هذه المهمة إلى إضافة فلتر جديد داخل موقع تعديل الصور، يقوم بتحويل الصورة إلى اللون الرمادي (أبيض وأسود) مع الحفاظ على لون واحد فقط يتم اختياره من قبل المستخدم، بالإضافة إلى توفير زر يسمح بإرجاع الصورة إلى وضعها الأصلي قبل أي تعديل.


المتطلبات الأساسية

تحويل الصورة إلى رمادي (Grayscale)
يتم تحويل جميع ألوان الصورة إلى درجات الرمادي.

الإبقاء على لون محدد
لون واحد فقط يبقى كما هو (مثل الأحمر أو الأزرق)، بينما باقي الألوان تصبح رمادية.

تمكين المستخدم من اختيار اللون
إضافة أداة (Color Picker) تسمح للمستخدم بتحديد اللون الذي يريد الإبقاء عليه.

زر إرجاع الصورة إلى وضعها الأصلي
يعيد الصورة كما كانت قبل تطبيق أي فلتر أو تعديل.

دمج الفلتر مع باقي أدوات التعديل
مثل السطوع، التباين، التشبع، التكبير


التقنيات المستخدمة في تنفيذ المهمة

HTML → لإضافة الأزرار وأداة اختيار اللون

CSS → لتنسيق شكل الأزرار والأدوات

JavaScript → لتنفيذ الفلتر والتعامل مع Canvas

Canvas API → لمعالجة بيانات الصورة (Pixels)

Django → لعرض الصفحة وإدارة المشروع

Git & GitHub → لتتبع التعديلات ورفع الكود


طريقة عمل الفلتر (بشكل مبسط)

يتم قراءة بيانات الصورة من الـ Canvas.

يتم فحص لون كل بكسل.

إذا كان قريب من اللون المختار → يبقى كما هو.

إذا كان مختلف → يتحول إلى رمادي.

يتم إعادة رسم الصورة بعد التعديل.

 زر الرجوع للصورة الأصلية

يقوم هذا الزر بـ:

تخزين نسخة من الصورة الأصلية عند تحميلها.

عند الضغط على زر "إعادة للأصل"، يتم استرجاع هذه النسخة.

يتم إلغاء جميع التعديلات والفلاتر.
